# 📱 Electronic Product Table

A simple HTML project that displays electronic product details in a table format. The table includes product names, quantities, unit prices, total amounts, and a final total. It also uses basic CSS styling and a hover effect for better readability.

## 📌 Features

- Electronic products displayed in a table
- Product Quantity and Price details
- Total Amount calculation
- Table Header Styling
- Row Hover Effect
- Clean and Simple Layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
Electronic-Product-Table/
│── index.html
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 📚 Concepts Used

- HTML Tables
- Table Rows and Columns
- `colspan`
- CSS Styling
- Hover Effects
- Border Collapse

## 📸 Output

The webpage displays:
- Electronic Product List
- Product Quantity
- Per Unit Price
- Amount
- Grand Total
- Hover effect on table rows
